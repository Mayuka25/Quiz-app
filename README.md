# Quiz App

A terminal-based quiz application built in Python that tests general knowledge through multiple-choice questions. It tracks your score in real time and gives you a detailed review of correct and incorrect answers at the end.

## Features
- Multiple-choice questions with instant answer checking
- Score tracking (correct/total)
- Percentage calculation with pass/fail result
- End-of-quiz review showing your answer vs. the correct answer

## How to Run
1. Clone this repository: git clone <your-repo-link>
2. Navigate into the project folder: cd quiz-app
3. Run the program: python quiz.py

## Tech Used
